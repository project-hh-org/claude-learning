## 한 줄 정의
목록 표에서 여러 항목을 고를 때 선택 범위(현재 페이지인지, 검색 결과 전체인지)를 사용자가 분명히 알 수 있게 하고, 그 범위만큼 일괄 작업을 거는 방식이다.

## 핵심
- 머리 체크는 기본적으로 현재 페이지만 고른다. 그 아래 선택 줄에 "이 페이지 N명 선택됨"과 "검색 결과 전체 M명 선택" 링크를 두어 범위를 한 단계 더 넓힌다.
- 전체 선택 상태에서는 선택 줄 문구가 전체 기준으로 바뀌어, 실제 작업 대상 수를 화면에서 확인할 수 있다.
- 검색 조건이나 필터가 바뀌면 선택을 비운다. 이전 조건의 대상이 남아 엉뚱한 항목에 작업이 가는 것을 막는다.
- 일괄 작업 대화상자에는 대상 수와 함께 작업에서 빠지는 항목 수(제외 수)를 보여 준다.

## 예시
"이 페이지 10명 선택됨 · 검색 결과 전체 486명 선택" 줄에서 전체 선택을 누르면 486명이 대상이 되고, 연장 대화상자는 대상 수와 제외 수를 함께 표시한다.
