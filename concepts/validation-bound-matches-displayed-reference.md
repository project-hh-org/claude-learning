## 한 줄 정의
사용자가 직접 입력하는 값의 검증 상한은, 화면에 안내하는 기준값과 같은 데이터에서 가져와야 한다.

## 핵심
- 계산 줄을 없애고 최종 값을 직접 입력받는 구조에서는 입력 칸이 유일한 계산 결과가 된다.
- 입력 검증은 보통 세 가지를 나눠 둔다: 필수(비었거나 0이면 막기), 상한(기준값 초과 막기), 도움말(상한을 문장으로 안내).
- 상한 기준이 화면 참고 정보와 다르면(예: 청구 금액과 실제 수납 금액) 사용자는 안내와 다른 결과를 보게 된다. 같은 필드를 기준으로 삼는다.
- 참고 정보는 남기되 계산식 자체는 빼서 입력 결과를 한 곳에서만 결정하게 한다.

## 예시
환불 금액 입력은 최종 환불금액을 필수로 받고, 결제 금액 이하인지 검증한다. 상한 값은 실제로 받은 금액으로 잡고, 도움말도 같은 금액을 보여 준다.
