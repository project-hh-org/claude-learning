## 한 줄 정의
모델이 상황을 보고 스스로 발동하는 기능에 기록 작업을 맡기지 않고, 시스템이 정해진 시점에 기록을 읽어 처리하도록 바꾸는 방식이다.

## 핵심
- 스킬은 모델이 발동 여부를 판단하므로 실제로 거의 발동하지 않았다. 설정 이후 대화 38개에서 캡처 스킬이 한 번도 언급되지 않았다는 확인이 근거다.
- 같은 문구 규칙을 더 강하게 써도 효과가 없었다. 지시를 늘리는 것보다 트리거 위치를 바꾸는 것이 효과적이다.
- 외부 트리거(hook 또는 주기 작업)는 정해진 시점에 항상 실행된다. 추출 로직은 공통 스크립트 하나로 두고 트리거만 여러 개 연결하면 재사용된다.
- 트리거마다 실행 환경이 다르므로(예: hook 전용 기능 여부) 어떤 도구에서 동작하는지 따로 확인해야 한다.

## 예시
에이전트 도구마다 hook이 없으면, 세션 기록 파일을 30분마다 읽는 launchd 작업으로 같은 추출 스크립트를 실행한다.
