## 한 줄 정의
다이얼로그의 열림 상태를 컴포넌트 state 대신 URL 쿼리 파라미터(예: `?key=id`)로 관리하는 방식이다.

## 핵심
- 열 때: 파라미터를 URL에 추가한다.
- 닫을 때: 파라미터를 URL에서 제거한다.
- 페이지 마운트 시: 파라미터를 읽어 값이 있으면 다이얼로그를 자동으로 연다.
- 결과: 다른 화면의 버튼이 해당 URL로 이동만 하면 같은 창이 열리고, 뒤로가기를 누르면 이전 URL 상태로 돌아가 창이 다시 열린다.
- 파라미터 값은 대상 데이터가 실제로 있는지 확인한 뒤 사용한다.

## 예시
상세 화면의 "담당자 변경" 버튼은 상세 안에서 창을 직접 띄우지 않고 `/목록?change=<id>`로 이동한다. 목록 페이지는 마운트 시 파라미터를 읽어 해당 항목의 변경 창을 연다. 닫으면 파라미터가 빠지고, 뒤로가기를 누르면 창이 다시 열린다.
