## 한 줄 정의
선택지가 하나로 줄어든 입력 칸이나 표 열은 사용자에게 정보를 주지 못하므로, 화면에서 빼는 쪽이 낫다.

## 핵심
- 목록의 모든 행이 같은 값이면 그 열은 구분 역할을 하지 못한다.
- 선택지가 하나뿐인 드롭다운·라디오는 입력 부담만 늘린다. 값을 고정하고 칸을 없앤다.
- 타입은 가능한 값을 하나의 리터럴로 좁히고, 외부와 맞물린 서버 계약(생성된 API 타입 등)은 건드리지 않는다.
- 시안(디자인)에 칸이 남아 있어도, 댓글 요구와 데이터 상태가 맞지 않으면 제거 근거를 남기고 확인을 받는다.

## 예시
결제 수단이 카드 하나로 통일되면 결제 수단 라디오, 목록의 수단 열, 수단 거르기 드롭다운을 제거하고, 카드 할부 개월처럼 카드에서만 의미 있는 입력은 그대로 둔다.
