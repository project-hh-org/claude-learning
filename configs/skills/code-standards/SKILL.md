# 코드·테스트 기준

항상 로드하던 규칙을 필요할 때만 읽도록 옮긴 것이다. 기본 원칙은 "주변 코드의 네이밍, 구조, 주석 밀도를 따른다"이고, 프로젝트 CLAUDE.md나 기존 코드와 충돌하면 그쪽이 우선이다.

- 네이밍, 함수 크기, 에러 처리, 타입 사용 기준이 필요하면 `code-quality.md`를 읽는다.
- 테스트를 새로 쓰거나 테스트 구조를 정할 때 `testing-standards.md`를 읽는다.
